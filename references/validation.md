## 地震基准

工具：`godot --path . --script res://tools/bench_quake.gd -- --budget=3`。
1280 × 720，关闭垂直同步，示例 fine 档；以下是相对空舞台的平均帧耗时增量。

| 示例 | 增量 ms |
|---|---:|
| 岩土 | 0.88 |
| 冰晶 | 0.56 |
| 熔岩 | 0.38 |
| 奥术 | 1.90 |
| 雷霆 | 1.02 |
| 暗影 | 0.71 |
| 圣光 | 1.97 |

该组案例全部达到 3 ms 基准目标。数值为本机平均帧增量，不是独立 GPU 用时或所有帧的上限；
部分案例 p95 超过 3 ms。群体、多节点叠加和其他设备不沿用此结论。
