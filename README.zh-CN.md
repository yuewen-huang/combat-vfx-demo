# combat-vfx-demo

[English](README.md)

用大白话描述一套连斩（招式、节奏、颜色、粗细），得到一个带格斗游戏打击感的 Godot 4 场景：
像素月牙刀光或轨迹刀光、星形命中火花、顿帧、击退、挑飞与下砸、震屏、连击数和终结技。
它是一个 AI 代理技能，仓库本身也是一个可以直接打开运行的 Godot 工程。
不需要外部美术素材或插件，所有特效都由代码绘制。

原有作品卡片的「编排」打开流程图，点击卡片仍然播放。旧作品保留原事件、时间与配色。
F11 / Alt+Enter 或工具栏按钮切换全屏，再次切换恢复原窗口。

- 地震：四种传播及反向、七种基础材质、分段节奏、GPU 网格动画、软件适配器降级。
- 群体：落叶、羽毛、沙漠三种独立材质；云团、路径流动、旋涡、球形聚集、爆散、飘落、消散。

示例：`quake_*`、`public_autumn`、`public_feathers`、`public_sand`、`public_multiskill`。

## 作为技能使用

把本文件夹放进代理的技能目录（Claude Code：`~/.claude/skills/combat-vfx-demo/`），然后这样说：

> 第一刀横斩，第二刀竖劈，第三刀上挑，第四刀旋转攻击，终极技能空中连斩。节奏 慢 慢 快快快。颜色黑红，中等宽度。

> 三下快速突刺，接居合一闪，金色终结。霓虹配色，细刀光。

没说的部分都用默认值。代理会按 [references/choreography.md](references/choreography.md) 把连招写成事件时间轴，
作为一个新场景加进你的 Godot 工程（或新建一个演示工程），跑自检，并查看结果的逐帧拼图。

## 刀光怎么选：月牙还是轨迹

两种画法都能做斩击。建议按表现目的选择：**需要看清武器怎么挥过去，选轨迹刀光；
需要强调完整的月牙轮廓、剑气造型或夸张的大斩击，选月牙刀光。** 终结技也可以用轨迹刀光，
例如下面的「断空九式」；招式名字本身不决定绘制方式。

| 画法 | 适合的表现 | `style.json` 配置 |
|---|---|---|
| 月牙刀光 | 大范围斩击、剑气造型、强调完整轮廓的攻击 | 不写 `renderer`，或设为 `""` |
| 轨迹刀光 | 贴着武器的挥砍、连续拼刀、旋转斩、需要自然拖尾和收尾的动作 | `"renderer": "ribbon"` |
| 爪痕 | 兽爪、利爪、撕扯：几道扇形张开的月牙形撕裂爪痕带细拖尾，招式有横斩、突进、交叉斩、直抓、大回环、暴扣，打中会在目标身上留下抓痕 | `"renderer": "claw"` |
| 魔法 | 脱手技能（`cast` 施法事件），原分辨率 + 着色器：骨架（起点、终点、路径、打击范围）带着本体和跟着本体变化的配饰；目前有火、雷、冰、风、沙 | `"renderer": "magic"` |

使用技能时直接说明选择，例如：

> 用轨迹刀光做一套连斩：两刀慢斩，接三刀快切，旋身上挑，最后重劈。蓝紫配色，金色终结。

> 用原来的月牙刀光做一套大斩击，突出清晰的月牙剑气轮廓。

目前代码按**整套演示**选择绘制器，不会根据招式自动逐刀切换；未配置 `renderer` 时仍使用月牙。
同一套中“普通挥砍用轨迹、最后一道剑气用月牙”的逐刀选择尚未实现。
`ribbon` 替换的是 `slash` 事件；命中火花、蓄力、直线刀痕等仍沿用现有实现。
这个选项只选择画法，不会自动增加飞行剑气等玩法。

轨迹刀光还需要配套编排时间：`slash.duration` 是挥刀时间，`tail` 是轨迹保留时间，
对应的 `hit.t` 应为 `slash.t + duration / 2`。不要只改绘制器名称而保留旧的命中时间。
完整例子见 [断空九式](combos/rift_dancer/README.md)，字段说明见
[事件格式](references/combo_events.md#sampled-trajectory-renderer)。

## 示例：提示词 → 效果

### 大元素使 · 万象归一 — [combos/element_master](combos/element_master)

约 19 秒，按剧本顺序：法阵归位 → 火，起（火球花冠）→ 冰，落（花冠收束、火球冻成冰枪插进地面）
→ 雷，连（一次施法、多个起终点串联，逐个引爆冰枪）→ 风，卷（龙卷卷着火、冰、雷）→
沙，缚（沙暴勒紧）→ 万象归一（长蓄力把所有元素吸进指尖，再射出五元素拧成的一道光束，五种爆炸同时炸开）。
用 `shape` 选形状，`element` + `mix` 选材质；坐标列表编排起终点，`linger` 留住本体，
`burst` 连锁引爆，`swell` 让形状扩大或收缩。镜头事件和魔法参数也能在手动精调里修改。
砸字、口播与音乐留给剪辑。

### 奇想组合 — [combos/odd_combos](combos/odd_combos)

九个没见过的组合，展示这套系统还能挖出什么：风火轮（火环掺风，跟着施法者冲过去撞爆）、
冰火双螺旋（同一条路，冰走直线、火绕着转）、雷冰法阵（法阵画在敌人身上，阵成即爆）、
千丝缝合（十六根沙丝从四面八方扎进目标）、火雷多米诺（两组火球交错挂成一排，`fuse`
让它们一颗接一颗被引爆）、雷沙龙卷、冰柱进军、元素牢笼（五元素环收紧后一起炸开）、冰雷天降。

### 形状 × 材质 — [combos/shape_mix](combos/shape_mix)

公共形状换别的材质：沙做的彗星、混了火和雷的风彗星、火的光束、雷的地柱、冰的漩涡、绕身爆开的火环。

### 火球 · 魔法 — [combos/fire_fireball](combos/fire_fireball)

魔法绘制器第一个成品：火球。依次是：
- 单发火球；
- 三连扇形火球；
- 蛇行火球；
- 螺旋火球；
- 在高空凝聚的巨型火球，砸到地面炸开，把目标掀飞。

魔法 = 骨架（起点、终点、路径、打击范围；速度曲线和时间是参数）+ 本体 + 跟着本体变化的配饰：
- 本体：翻滚的火球，在起点凝聚，飞得越快拉得越长；
- 凝聚时：火星螺旋汇入；
- 出手时：一闪；
- 飞行中：火焰拖尾、身后的热浪扭曲（越快越长）、往后甩的余烬、留在路径上的烟，地面上一片橙光，越低越亮；
- 落点：闪光和横向光带、翻滚上升的火球、扭曲空气的冲击波、弹跳的余烬、碎块、烟柱；在地面炸开时还会留下火苗和带余火的焦痕，目标身上继续着火。

**魔法画质**有四档，写在 `style.json` 的 `"magic_quality"` 里，精调画面里能选，播放时按 Q 也能切换：
- `"retro"` 复古：用像素颗粒和一圈圈色阶光晕画成像素风；
- `"balanced"` 均衡：原分辨率，粒子约三分之一，光晕小一些，适合配置弱的电脑；
- `"ultimate"` 极致：去掉热浪扭曲和冲击波折射，粒子减半左右；
- `"explosive"` 炸裂：默认，就是上面这些全部。

事件格式见[魔法绘制器](references/combo_events.md#magic-renderer)。

### 闪电 · 魔法 — [combos/thunder_bolt](combos/thunder_bolt)

按火球的套路做的闪电。五招依次是：
- 掌心雷；
- 三连弧雷；
- 蛇行雷；
- 头顶落雷两连；
- 天罚：雷云压顶，劈到地上烧出树枝状的放电纹，把目标掀飞。

- 本体：闪电主干，沿路径折出锯齿。主干形状在一次劈击里保持不变，只有细碎的电流在跳。
- 蓄电：起点聚起一团噼啪作响的电球，火花被吸进去，小电弧往外乱窜，空气变暗；从高空起手时还会聚起雷云，云里一闪一闪。
- 先导：一道细细的先导一节节探下去，头上有电光，旁边有试探的小分叉。
- 劈中：整条主干全亮，带着分叉连闪几次，主干周围爬着细碎的电弧（第一下最密，之后变稀），全屏白闪，最后留下一道淡紫色残影。
- 落点：蓝白闪光，电弧炸开，火花落地弹跳，冲击波震裂空气；劈到地面时会烧出一张树枝状的放电纹（利希滕贝格图），先发蓝光，再冷却成焦痕；目标身上持续冒电弧，一抽一抽地闪白。

雷有两个专属参数：`hold`（劈中后持续闪多久）、`jag`（折角，锯齿感）。

### 冰 · 魔法 — [combos/ice_spear](combos/ice_spear)

依次是：
- 冰锥：打中后目标被冻住，推不动；
- 三连冰锥；
- 暴雨梨花；
- 寒霜结界：减速状态下目标被打飞也是慢的，最后结界碎裂。

- 本体：透亮的双尖六棱冰晶，绕自身长轴滚转，越大转得越慢，转起来光会在晶面之间移动。有亮白的棱线、锐利的高光、内部细裂纹；炸裂档还能透过冰晶看到后面被折射扭曲的画面。
- 冰绝不走曲线：不管路径填什么，冰都笔直飞向目标。
- 凝聚：一节节结晶成形，冰尘飘进来，施法者脚下结霜。飞行中越飞越快，身后留下细长的冷气丝、闪烁的冰尘和冷空气速度线。
- 落点：透明冰晶炸出来又碎掉，冰片翻滚滚转（越小转得越快），落地后闪光消失，地面结霜。
- 冻结：透明冰晶从目标脚下往上长，把目标封住；目标推不动，直到冰晶碎掉。终结技会直接震碎冰晶。
- 暴雨梨花：从“自身”起手、数量多时，冰针先悬浮在角色身后，形成一团（散开参数决定这团有多大），停顿之后依次笔直射出。
- 寒霜结界：起点“目标身上”，路径“原地”。一圈冰晶悬浮在目标周围，跟着目标走，不停冒出往下沉的浓雾。持续期间目标的击退、浮空、下落都只有 0.3 倍速度；最后一次落点时，冰晶向外炸碎。

### 风 · 魔法 — [combos/wind_blade](combos/wind_blade)

依次是：
- 气团；
- 三连回旋气团；
- 蛇行气团；
- 龙卷。

- 本体：白色小气团，几股软软的白气绕着一个亮芯翻滚，外面裹着两道旋转的白色涡纹，飞得越快拉得越扁长。风可以自由走曲线（默认弧线，起手快）。
- 凝聚：气流螺旋汇入，气团从无到有卷起来。
- 飞行：一路散出小气团，变大、变淡；后面拖着淡淡的风痕，偶尔卷起几片叶子，贴地飞时扬起尘土。
- 落点：气团炸成一圈翻滚的白气，白色涡纹旋开，气浪打着旋向外冲；目标身上一阵阵风在抽打。
- 龙卷：起点“目标身上”，路径“原地”。漏斗由一团团白气和几条宽的白色螺旋气流组成，前层亮、后层暗。轴心像绳子一样扭动，鼓包沿着漏斗往上走。
- 龙卷的发力写在形状上：每次命中前先收紧、绷直蓄势；命中那一下猛地张开、拔高、转得更快、甩动，脚下炸起一圈尘土，然后慢慢松开。最后一次命中时炸开，把目标甩出去。

### 沙 · 魔法 — [combos/sand_silk](combos/sand_silk)

依次是：
- 沙丝；
- 三连沙丝；
- 沙暴；
- 千丝。

- 沙魔法是光，不是沙堆：空气里飘着淡淡的、一闪一闪的沙金色细粒。
- 施法：细粒从四周被吸过来，汇到起点凝成一个光点，再拉成一根很细的沙丝。沙丝由一颗颗紧挨着、各自闪烁的金色细粒组成，旁边缠着两根更淡的丝。它沿路径射出，贯穿目标，绷直一小会儿后散成细粒飘走。
- 落点：贯穿处一点亮光，几根金丝向外弹出又收回，一蓬闪烁的金粉散开、悬停、慢慢飘落。
- 状态：金色细粒附在目标身上慢慢往下落，还缠着一根细丝，目标轻微减速。
- 沙暴：起点“目标身上”，路径“原地”。几十根很细很密的沙丝绕着目标飞旋，每根高度、倾角、速度都不一样，前亮后淡，中间卷着金粉；每次命中时丝会收紧，最后一次命中时散成金粉。

### 变体试验 · 雷盾 / 地火 — [combos/magic_variants](combos/magic_variants)

用现有的骨架加三个取值（起点“自身/地底”、终点“自身”、路径“原地”）做出的变体：
- **雷盾**：起点、终点都是自身，路径“原地”。贴身的电弧护盾跟着角色走，碰到目标不造成伤害；时间到了向外炸开，伤害打在角色周围。
- **地火**：起点“地底”。地面先裂开、透出岩浆色的光，接着炎柱喷出、持续燃烧，燃烧期间按间隔连续命中。

### 裂魂爪 · 回环暴扣 · 爪痕 — [combos/claw_cyclone](combos/claw_cyclone)

> 爪痕绘制器演示：横斩、反手横斩、突进、交叉斩、后撤接大回环螺旋挑空、空中撕扯、蓄力暴扣砸地留下地面爪痕。

九击。**横斩**和**反手横斩**两道横向爪痕；**突进**整个人冲上去，四道爪痕刺穿目标；**交叉斩**两爪交成 X，目标身上留下 X 形抓痕；
后撤一步接**大回环**：一圈半、半径越转越大的四爪螺旋把目标挑飞；追上去空中两抓；
最后蓄力，金色四爪从高处**暴扣**穿过目标砸进地面，四爪扎进地面、碎石飞溅，地面向两侧裂开。

每道爪痕都是月牙形的撕裂口子（细长尾、鼓起的爪腹、尖锐爪尖、毛糙边缘），扇形张开、长短不一、依次落下，后面带一条细拖尾。
每次命中都会在目标身上留下顺着这一爪方向的抓痕。`style.json` 选择 `"renderer": "claw"`。

## 提示词对照：什么说法对应哪组特效

把需求按 **画法 → 招式顺序 → 节奏 → 命中反馈 → 外观** 写出来即可。
下面是代理编排演示时的对应关系：代理会把自然语言写成时间轴和风格配置，工程本身没有关键词解析器。

### 先说画法：刀光怎么出现

| 你可以这样说 | 对应的画面 | 选择 |
|---|---|---|
| “用轨迹刀光”“刀光跟着挥刀走” | 刀锋扫过后留下带状轨迹，旧段变细、变暗再消失 | `renderer: ribbon`；适合挥砍、拼刀、旋转斩 |
| “用原来的月牙”“完整的大月牙轮廓” | 预设月牙快速展开，再从尾端侵蚀收掉 | 默认绘制器；适合强调完整形状的大斩击 |
| “用水墨笔触”“要干笔、飞白、墨滴” | 笔腹、纤维和墨滴组成的独立水墨画法 | `renderer: ink`；参考「墨势六式」 |

画法按整套演示选择；只说“横斩”或“上挑”不代表自动切换绘制器。
不指定画法仍使用默认月牙。单纯选择 `ink` 配色预设也不会自动启用水墨笔触绘制器。

### 再说招式：往哪挥，打中后发生什么

| 你可以这样说 | 招式与目标反应 |
|---|---|
| “横扫一刀” | 横向展开的挥砍；小幅击退可另外指定 |
| “从头顶向下劈” | 从高到低挥刀；不会仅凭“下劈”就把目标挑空或砸地 |
| “两刀交叉成 X” | 两刀相反倾斜方向的斩击，分别命中 |
| “三次快速突刺，每次向前一点” | 三次细长刺击，分配少量前冲；当前直刺示例使用默认绘制器的扁平刀光 |
| “旋转两圈，每圈命中一次” | 刀光绕攻击方转两圈，共两次命中；圈数和命中数分别写清楚 |
| “向上挥一刀，把目标挑飞” | 上挥斩击，加向上的受击速度；“向上挥”指定方向，“挑飞”指定目标反应 |
| “跳起追上目标，空中连斩三次” | 攻击方追到空中，三次轻击续浮空；每刀可换方向 |
| “空中重劈，把目标砸回地面” | 下劈配向下的受击速度，目标落地并反弹；若还要终结光圈，明确说“作为终结技” |
| “向前冲一段，再横斩” | 前冲位移接横扫，刀光跟随攻击方 |
| “蓄力后居合一闪，穿过目标，延迟三道刀痕” | 蓄力、瞬移穿身、三次延迟刀痕，再接指定的命中；刀痕使用现有直线效果 |

同一种招式可以用不同刀光表现。攻击方目前是菱形标记、目标是方块；这些说法编排的是
位移、特效和受击反应，不会自动生成角色挥刀动画。

### 最后说节奏、力度和外观

| 你可以这样说 | 调整内容 |
|---|---|
| “慢、慢、快快快，停一拍，再重劈” | 前两刀留出间隔，接紧凑三连切，最后停顿蓄势；顿帧额外叠加，不挤掉出刀间隔 |
| “这一刀收快一点”“拖尾留久一点” | 调挥刀与收尾时间；轨迹刀光分别用 `duration` 控制挥刀、`tail` 控制轨迹保留时间 |
| “轻击，小幅击退，轻微震屏” | 小命中火花、短顿帧、轻击退和轻震屏 |
| “最后一下作为终结技，金色，重顿帧” | 放大命中火花和光圈，加长顿帧、增强震屏；最后一击完成后连击数使用强调色 |
| “普通刀光冰蓝，终结金色” | 分配普通色和强调色，并调整背景对比；没有指定用途的两种颜色通常按此分配 |
| “ember 配色”“neon 配色”“ink 配色” | 使用相应预设的色板与场景颜色；画法仍按上面的选择配置 |
| “细 / 中等 / 粗刀光” | 宽度倍率约为 ×0.6 / ×1.0 / ×1.4 |
| “细腻 / 颗粒粗 / 复古像素” | 每个纹理像素对应 2 / 4–5 / 6 个世界像素，默认 3 |

一个完整的例子：

> 用轨迹刀光。先横扫，再反向斜斩，接三刀快速交叉切；停一拍，旋身上挑把目标挑飞，
> 跳起追切两刀，最后重劈砸地作为终结技。前两刀慢，中间快，终结前留停顿。
> 普通刀光蓝紫交替，终结金色，中等宽度，像素 3。轻击微震，终结重顿帧。

没指定的部分由代理按 SKILL 默认值补齐：3～4 刀变化的连招，以上挑和终结收尾，
钢蓝色、中等粗细、像素 3，界面语言跟随提示词。出图后可以直接说“第二刀晚一点”
或“最后一刀再宽一些”，针对某一刀继续调整。

## 手动使用

```bash
python tools/new_combo.py my_combo --combo my_combo.json --style styles/neon.json --thickness bold
python tools/verify_combo.py my_combo --gif --godot /path/to/godot
```

这会在本工程里新增 `combos/my_combo/my_combo.tscn`，画廊里会自动出现它。
加 `--project 目录` 则加到别的 Godot 工程里（会把 `vfx/` 脚本复制过去）；目录是新的或空的，就新建一个演示工程。
verify_combo.py 加 `--media` 会把 GIF 和拼图复制到 `media/`。事件格式见 [references/combo_events.md](references/combo_events.md)（英文）。

参数：
- `--thickness`：thin、medium、bold 或一个数字；
- `--pixel`：像素颗粒大小；
- `--lang`：界面语言，en 或 zh；
- `--title`：标题；
- `--prompt`：提示词原文，存为 prompt.md；
- `--palette NAME=色,色,色,色`：替换一套刀光色板，从亮到暗；
- `--color 角色=色`：替换场景颜色。

## 自定义绘制器

风格预设（`default`、`ember`、`neon`、`ink`）只改颜色、粗细和像素颗粒。如果不喜欢现成的画法，
想换一种**绘制方式**（水墨、剪纸、矢量辉光、手绘序列帧……），就加一个绘制器。
事件时间轴、顿帧、击退、震屏、重播按键、慢放、录帧和自检都是共用的，绘制器只决定每个事件画成什么。

1. **舞台脚本**：新建 `vfx/<名字>_stage.gd`，`extends ComboStage`（保留 `@tool`）。只重写想换画法的部分，其余交给 `super`：
   - `_fire(event)`：`slash`、`charge`、`flash_step`、`cut` 等；不处理的事件调用 `super._fire(event)`；
   - `_hit(event)`：命中。保留默认实现里的记账——`hits += 1`、`_target_velocity`、`_stop = event.stop`、`_shake(...)`——否则自检和打击感会坏；
   - `_draw()` / `_refresh()`：需要时换背景和画面文字。
2. **特效节点**：你生成的笔触、火花等。任何 `Node2D` 加到 `fx`（舞台坐标）或 `attacker`（跟随攻击方）下，
   只要有 `advance(delta)` 和 `is_done()` 就行：舞台按连招时钟推进它（顿帧和慢放也会冻结它），结束后自动释放。
   在 `_draw()` 里画，不要用 `_process` 或真实时间。
3. **启用**：在连招的 `style.json` 里写 `"renderer": "<名字>"`，`combo_player.gd` 就会加载 `vfx/<名字>_stage.gd`；
   不写就用默认像素绘制器。
4. **自定义事件字段**：舞台可以读 `combo.json` 里自己的字段（水墨绘制器读 `ink_kind`），其他绘制器会忽略。
5. **检查**：`verify_combo.py <连招> --gif` 照样跑命中数自检和逐帧拼图；绘制器特有的检查可以仿照
   `tools/verify_ink_forms.gd` 另写脚本。

水墨绘制器就是现成的范例：[vfx/ink_stage.gd](vfx/ink_stage.gd)（约 100 行）和 [vfx/ink_stroke.gd](vfx/ink_stroke.gd)（约 120 行）。
也可以让代理来做：说“新做一个 X 风格的绘制器，不要给现有刀光换色”，并让它参考这一节。
